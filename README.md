# Low-Level Design (LLD)

This repository contains Low-Level Design concepts, design pattern implementations, and interview-oriented problems.  
It is intended for LLD interviews, system design fundamentals, and real-world Java development.

---

## SOLID Principles

This section covers the five SOLID principles, which form the foundation of good object-oriented design.

Principles included:

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

Goal: Write flexible, maintainable, and scalable object-oriented code by following proven design principles.

---

## Design Patterns

This section covers the three major categories of design patterns with clear implementations and use cases.

### Creational Design Patterns

Focus on object creation and hide instantiation logic to make systems flexible and maintainable.

Patterns included:

- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

Goal: Control object creation and reduce dependency on concrete implementations.

---

### Structural Design Patterns

Focus on how classes and objects are composed to form larger structures.

Patterns included:

- Adapter
- Bridge
- Composite
- Decorator
- Facade
- Flyweight
- Proxy

Goal: Allow incompatible components to work together and improve system structure.

---

### Behavioral Design Patterns

Focus on communication between objects and responsibility assignment.

Patterns included:

- Observer
- Strategy
- Command
- Chain of Responsibility
- Mediator
- State
- Template Method
- Visitor
- Iterator
- Memento
- Interpreter

Goal: Improve object interaction while keeping components loosely coupled.
